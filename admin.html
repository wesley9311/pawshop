数据备份

邮件通知 EmailJS·可选

配置后顾客下单自动发确认邮件、录单号自动发发货通知。emailjs.com 免费 200 封/月。模板变量:{{to_email}} {{order_id}} {{items}} {{total}} {{status}} {{carrier}} {{tracking}}

线上同步 GitHub·商品目录全设备实时

配置后,商品改动自动写回线上仓库的 catalog.json,所有设备(含手机)1 分钟内同步。Token 创建:GitHub → Settings → Developer settings → Fine-grained tokens → Generate → Repository access 选 Only pawshop → Permissions 里 Contents 设 Read and write → 复制。Token 只存你本机浏览器。

AI 解析配置 智谱 GLM·智能粘贴用

open.bigmodel.cn 的 API Key,用于商品表单"AI 解析"按钮:粘贴中文商品文字→自动产出英文名称/描述/分类/参数。Key 只存本机浏览器。免费模型高峰期可能繁忙,会自动重试一次。

图床配置 imgbb·商品图片上传用

imgbb.com 免费注册(邮箱即可) → 头像菜单 API → 复制 API Key 填到这里。Key 只存在你本机浏览器,不进公开仓库。之后商品编辑页"从电脑上传"即可自动生成图片链接(永久有效,全球可访问)。
